# 发布窗口冲突检查台

核对一个服务是否在同一时段安排了多次变更。直接打开 `index.html` 即可使用。无需登录或安装依赖，清单留在当前页面。

1. 从表格复制三列：服务名、开始时间、结束时间。用制表符分列，一行一条。
2. 时间用北京时间 `YYYY-MM-DD HH:mm`。点击「示例」可以试跑一组虚构的排期。
3. 点击「检查」。冲突明细会给出原行号、重叠的起止和分钟数。格式有误的行会单独列出，其余行仍会检查。

两个窗口只在结束与开始处相接时可以共存。不同服务各自检查，同名服务以去除首尾空白后的文本为准。页面最多接受 300 个非空行，支持跨日和闰日。此工具用于核对时间重叠，团队的发布审批、跨服务依赖和缓冲时间需要另外核实。

`index.html` 是完整静态应用，包含 `analyze` 纯函数和交互界面。核心代码和界面由华为云码道 CodeArts 生成，交付前校对了超限提示、公历年份和复制提示等边界。

用 Node.js 运行独立验证：`node --test tests.cjs`。
